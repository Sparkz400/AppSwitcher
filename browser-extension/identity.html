AppSwitcher

This tab identifies the website beside it so AppSwitcher can find it after a browser restart.

Keep both tabs together in this group. Move the whole group if you want another window. Do not duplicate or remove this identity tab.

If this is a new website, the other tab will open it when the connection is ready. Use the AppSwitcher extension button for connection details.

Dieser Tab identifiziert die Webseite daneben. Lassen Sie beide Tabs zusammen in dieser Gruppe. Verschieben Sie immer die ganze Gruppe. Diesen Identitäts-Tab nicht duplizieren, schließen oder auf eine andere Adresse umleiten. Verbindungsdetails finden Sie über die AppSwitcher-Erweiterung in der Symbolleiste.
