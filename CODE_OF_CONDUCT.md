# Code of conduct

AppSwitcher welcomes contributors with different backgrounds and experience. This applies to issues, pull requests and other project spaces, and when representing this project elsewhere.

- Be respectful, patient and specific. Critique ideas and code without attacking people.
- Welcome questions and acknowledge mistakes. Respect accessibility needs and differing experience.
- Do not harass, threaten, discriminate, make unwanted sexual comments, or publish another person's private information.
- Do not post credentials, customer data or private logs. Use synthetic examples.

Maintainers may edit or remove harmful content, close or lock a discussion, or restrict participation. Responses should reflect the severity and repetition of the behavior; serious threats or disclosure of private information can warrant immediate restriction. These expectations apply to maintainers too.

For abuse, threats or exposed private information, use GitHub's **Report content** menu on the relevant comment or profile to contact GitHub privately. Do not open a public issue containing sensitive evidence or repeat the harmful content. See [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

For ordinary project moderation, you may ask a maintainer in the affected discussion without repeating private details. GitHub's reporting route is also available when a maintainer is involved. This project has no separate confidential conduct-report inbox and cannot promise a response time. Security vulnerabilities have their own [private reporting route](SECURITY.md).
