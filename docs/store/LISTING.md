## English

Short description: Restore and activate the website tabs managed by AppSwitcher.

Description:

Connect your browser to AppSwitcher, the open-source Windows application launcher for operator and maintenance workstations.

AppSwitcher Browser Bridge lets the desktop application open, restore and activate its managed website tabs. It keeps a local ownership record so that repeated activation can return to the same tab, including after supported browser session restoration. When ownership or connection state is uncertain, it reports the problem instead of opening another tab as a guess. Unrelated tabs remain outside AppSwitcher's managed set.

Give this browser profile a recognizable name, select it in AppSwitcher's website settings, and enable the browser's option to reopen previous windows and tabs. Pairing and browser session restoration are separate setup steps.

The Windows AppSwitcher application and its native messaging bridge are required. This extension does not work as a standalone launcher. The desktop app and documentation are available from the project website. Internet access is needed for online websites and store installation; the desktop application also supports a separate offline deployment package.

The extension stores profile identifiers and managed-tab recovery records locally. It exchanges commands and managed-tab status with the local Windows application. It has no analytics, advertising, external telemetry service, remote executable code or sale of browsing data. See the privacy policy for the tab metadata it accesses and how to remove local data.

## Deutsch

Kurzbeschreibung: Von AppSwitcher verwaltete Website-Tabs wiederherstellen und aktivieren.

Beschreibung:

Verbinden Sie Ihren Browser mit AppSwitcher, dem quelloffenen Windows-Anwendungsstarter für Bedien- und Wartungsarbeitsplätze.

AppSwitcher Browser Bridge ermöglicht der Desktop-Anwendung, ihre verwalteten Website-Tabs zu öffnen, wiederherzustellen und zu aktivieren. Lokale Zuordnungen helfen dabei, beim erneuten Aufrufen zum selben Tab zurückzukehren, auch nach einer unterstützten Sitzungswiederherstellung des Browsers. Wenn die Verbindung oder Zuordnung unklar ist, wird das Problem gemeldet, statt auf Verdacht einen weiteren Tab zu öffnen. Andere Tabs werden nicht als AppSwitcher-Tabs übernommen.

Geben Sie dem Browserprofil einen erkennbaren Namen, wählen Sie es in den Website-Einstellungen von AppSwitcher aus und aktivieren Sie im Browser das erneute Öffnen vorheriger Fenster und Tabs. Kopplung und Sitzungswiederherstellung sind getrennte Einrichtungsschritte.

Die Windows-Anwendung AppSwitcher und ihre lokale Browser-Verbindung sind erforderlich. Diese Erweiterung ist kein eigenständiger Anwendungsstarter. Anwendung und Anleitung sind auf der Projektseite verfügbar. Online-Websites und die Store-Installation benötigen eine Internetverbindung; für die Desktop-Anwendung gibt es außerdem ein separates Offline-Paket.

Profilkennungen und Wiederherstellungsdaten verwalteter Tabs werden lokal gespeichert. Befehle und der Status verwalteter Tabs werden mit der lokalen Windows-Anwendung ausgetauscht. Die Erweiterung enthält keine Analyse- oder Werbedienste, keine externe Telemetrie und keinen nachgeladenen ausführbaren Code und verkauft keine Browserdaten. Die Datenschutzhinweise beschreiben die verwendeten Tab-Daten und das Entfernen lokaler Daten.
