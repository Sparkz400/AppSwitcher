# Getting help

Start with [common setup problems](docs/TROUBLESHOOTING.md) and the [keyboard reference](docs/KEYBOARD.md). For more detail, use the [installation guide](docs/INSTALLATION.md), [browser setup](docs/BROWSER_INTEGRATION.md), [operations guide](docs/OPERATIONS.md) and [safe examples](examples/README.md).

If you are still stuck, search [existing issues](https://github.com/Sparkz400/AppSwitcher/issues). Then choose the appropriate route:

- [Ask a usage or setup question](https://github.com/Sparkz400/AppSwitcher/issues/new?template=question.yml). Describe the goal and what you have already tried.
- [Report a reproducible bug](https://github.com/Sparkz400/AppSwitcher/issues/new?template=bug_report.yml). Include the AppSwitcher version, Windows/browser versions and minimal reproduction steps.
- [Suggest an improvement](https://github.com/Sparkz400/AppSwitcher/issues/new?template=feature_request.yml). Check the [roadmap](ROADMAP.md) first.
- [Report a vulnerability privately](SECURITY.md). Do not use a public issue for security-sensitive details.
- For community behavior, follow the [code of conduct](CODE_OF_CONDUCT.md).

Issues are public. Remove credentials, PIN hashes, machine/customer names, private URLs and personal paths from examples and screenshots. Do not upload your complete settings file or diagnostics without inspecting and sanitizing them first. A small synthetic example is usually more useful.

This is a community-maintained beta with no guaranteed response time or paid support service. Maintainers may request a smaller reproduction or close duplicate and inactive reports. See [maintenance and compatibility](MAINTENANCE.md) and [workstation acceptance](docs/WORKSTATION_ACCEPTANCE.md) before planning a deployment.
